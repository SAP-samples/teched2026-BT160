# Exercise 4 — Enrich with Web Research and Check EU AI Act Exposure

## Overview

Your review so far is built entirely from internal sources. The **re-platform / retire** decision needs an outside view: is MaMa-CRM's technology stack a dead end, and what would replace it? In this exercise you use the EA Assistant's web-research capability to close that gap — researching technology currency, scoping credible replacement options, and locking the chosen successor into the inventory.

**Duration:** 15 minutes

## Web Research: Is the Stack a Dead End?

MaMa-CRM runs on Java, Oracle, and the Drools rule engine, with persistence generated from a UML model and DSLs for its data formats. The arc42 documentation tells you *what* the stack is. The web tells you whether that stack is a liability in 2026.

### Step 1 — Research Technology Currency

⌨️ **➤ Ask the EA Assistant:**

> *"Using web research, assess the current support and end-of-life status of MaMa-CRM's core technologies: the Java runtime, Oracle Database, and the Drools rule engine. For each, note the latest supported versions and any end-of-support dates that would make a current deployment a risk. Cite your sources."*

Compare what you learn to criterion 4 (Technology Currency) from Exercise 3. Does the web view strengthen a gap you already found, or soften it?

### Step 2 — Scope the Alternatives

If the leaning is toward re-platform or retire, the Board will ask "replace it with what?"

⌨️ **➤ Ask the EA Assistant:**

> *"Using web research, identify two or three credible options for a mass-market, multi-mandator CRM / customer-communication platform that could replace a self-built system like MaMa-CRM — including at least one SAP option. For each, give a one-line fit summary against MaMa-CRM's core need: onboarding a new mandator or campaign without changing code."*

> [!NOTE]
> **Why this matters:** A retire or re-platform recommendation without a credible successor is not actionable. The EA Assistant's web research lets you attach real options to the recommendation — the difference between "this is a problem" and "here is the path."

Pick the option you find most compelling. Then lock it into the inventory so it travels with the recommendation.

⌨️ **➤ Ask the EA Assistant:**

> *"Create an Application fact sheet in LeanIX for the replacement platform we just selected. Set its lifecycle to active. Add a brief description based on the research — what it is, who makes it, and why it fits InDAC's need. Return the fact sheet ID and URL."*

> [!NOTE]
> You will link this fact sheet to MaMa-CRM as its successor and include it in the initiative in Exercise 5. Creating it here, at the point where you made the decision, keeps the evidence trail intact.

### Step 3 — Fold the Web Findings Into the Picture

⌨️ **➤ Ask the EA Assistant:**

> *"Add the technology-currency web findings to the gap register from the earlier assessment. Re-rank the gaps if the new evidence changes their severity, and note any gap where an external source now gives us higher confidence than internal data alone did."*

## Summary

Your review now combines internal evidence with an outside view of the technology stack and a credible successor locked into the inventory. You have everything you need to make the call. In Exercise 5, you will synthesize it into the keep / re-platform / retire verdict and prepare your shareback.
